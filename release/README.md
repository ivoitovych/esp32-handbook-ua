# Готові PDF

Складені файли ревізії — щоб книгу можна було взяти й надрукувати, не
ставлячи спершу `pandoc` і Typst.

| Файл | Що це | Формат |
|---|---|---|
| `esp32-dovidnyk.pdf` | **основна книга** — вступ, 63 розділи, 15 карток, 8 додатків, 3 вкладиші | A5, 398 стор. |
| `esp32-kartky.pdf` | лише картки К1–К15, по одній на сторінку | A4, 15 стор. |
| `esp32-proekty.pdf` | лише проєкти 59–63 | A5, 28 стор. |

**Основний деліверабл — `esp32-dovidnyk.pdf`.** Два інші файли не
доповнюють його, а витягують із нього частини під окремий спосіб
користування: картки друкують на A4 і ламінують, щоб носити в кишені
(тому вони окремим файлом і в іншому форматі), проєкти — щоб віддати
разом із пристроєм.

## Верстання основної книги

A5 (148 × 210 мм), двобічний друк: непарні сторінки праворуч, парні
ліворуч. Поля враховують палітурку — внутрішнє більше за зовнішнє, тож
друкувати треба саме двобічно, інакше поля з'їдуть.

Колонцифра стоїть на зовнішньому краї, колонтитул називає частину на
парних сторінках і розділ на непарних. Частини відкриваються окремою
сторінкою-шмуцтитулом.

## Як перезібрати

```sh
make setup      # один раз у новому клоні
make dovidnyk   # → build/esp32-dovidnyk.pdf
```

Файли в цьому каталозі оновлюються **свідомо, на віхах**, а не при
кожному збиранні: інакше кожна дрібна правка тексту важила б у git
п'ять мегабайтів. Робочий вивід збирання лишається в `build/`, який до
репозиторію не входить.

Дата ревізії стоїть на титульній сторінці й у колофоні. Що звірено з
першоджерелом і коли — `docs/fakty.md`; звіти сесій рецензування —
каталог `reviews/`.
