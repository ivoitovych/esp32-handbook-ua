# Аудит покриття тем

Надлишковий перелік тем, які взагалі можуть стосуватися ESP32 у ролі,
описаній у цьому довіднику. Мета переліку — не покрити все, а зробити
кожну **відсутність рішенням, а не забудькуватістю** (Р14).

Прогін по цьому файлу робиться перед freeze кожної major-ревізії.
Для кожного рядка одна з двох відповідей:

- **де покрито** — номер розділу, картки чи додатка;
- **свідомо поза межами** — з причиною.

Третьої відповіді («не подумали») бути не має: якщо рядок опинився без
відмітки, це знахідка аудиту.

Останній прогін: **2026-08-26**, перед першою повною збіркою.

## Як користуватися при наступному прогоні

1. Пройти перелік згори вниз, для кожного рядка перевірити, що
   зазначене місце **справді існує** і справді про це.
2. Кожну відмітку «свідомо поза межами» перечитати заново: рішення могло
   застаріти разом із платформою (наприклад, USB-host на S3 або тести).
3. Додати рядки для тем, що з'явилися між ревізіями.
4. Знахідки — у звіт рецензії в `reviews/`, як і решта.
