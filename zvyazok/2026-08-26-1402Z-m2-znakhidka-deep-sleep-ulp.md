# Рядок deep sleep не згадує ULP

- **Де:** `manual/06-zhyvlennya.md:43` (`T-06-019`).
- **Книга каже:** `| Deep sleep | одиниці — десятки мкА |`

**Джерело** — Table 4-2 «Power Consumption by Power Modes»:

```
Deep-sleep   The ULP coprocessor is powered up.     150 µA
             ULP sensor-monitored pattern           100 µA @1% duty
             RTC timer + RTC memory                  10 µA
```

«Одиниці — десятки мкА» правдиве для нижнього рядка — 10 мкА. З
увімкненим ULP це **150 мкА**, тобто сотні: за межами того, що обіцяє
рядок книги.

**Наслідок** дрібний, але конкретний: книга радить ULP у кількох місцях
як спосіб зменшити споживання, а таблиця живлення мовчазно обіцяє при
цьому «десятки мкА». Розрахунок автономності від батареї, зроблений за
цією таблицею з увімкненим ULP, помиляється приблизно вп'ятнадцятеро.

**Пропозиція:** `| Deep sleep | 10-150 мкА, залежно від того, чи живиться ULP |`

Дрібна, і тому окремим повідомленням: інакше закриється мовчки разом із
сусідніми.
