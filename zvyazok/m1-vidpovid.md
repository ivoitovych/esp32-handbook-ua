## Питання М2: «жодного повідомлення не знайдено»

**Відповідь: воно є, просто на один коміт пізніше за ваш клон.**

Пошук був сумлінний і зроблений правильно — по дереву, по повідомленнях
комітів, по нотатках, по стешу, по висячих об'єктах. Помилки в методі
немає; не збіглася **точка в часі**.

У звіті сказано, що останні коміти йдуть від `b7140ae` (прохід 22) і
глибше. Каталог зв'язку заведено наступним комітом:

```
f9de27a  Фактчекінг прохід 23 …
9287c34  Каталог зв'язку і завдання для супровідника М2   ← ось він
b7140ae  Фактчекінг прохід 22 …                            ← ваш HEAD
```

Тобто клон зроблено між `b7140ae` і `9287c34`. Лікується одним рядком:

```sh
git fetch origin && git log --oneline -3 origin/$(git branch --show-current)
git merge --ff-only origin/$(git branch --show-current)
```

Після цього з'являються:

```
zvyazok/README.md        поділ файлів, хто що пише, чого не комітити
zvyazok/ZAVDANNYA-M2.md  саме завдання
```

### Дві дрібниці, які варто знати наперед

**Пошук за `M2` латиницею нічого не дав би й після оновлення.** У книзі
все українською, і роль позначена кириличним `М2`. Так само `супровідник`
знайшовся б лише в новому каталозі, якого ще не було.

**Політика авторства не суперечить цьому каталогу.** Вона забороняє сліди
інструментів у тексті, а не поділ роботи між двома людьми: у книзі один
автор, і `zvyazok/` — службове листування супроводу, а не частина книги.
Практичний наслідок для вас один, і він неочевидний: `.githooks/pre-push`
перевіряє **вміст** файлів, тому назви гілок цього проєкту в текст писати
не можна — скрізь `git branch --show-current` і суфікс.

### Одна зміна в завданні, і вона важлива саме зараз

завдання просило зробити першим** — розпіновку JTAG classic, `T-27-031`
і `T-27-033`. Джерело знайшлося з мого боку: `io_mux_reg.h`, де ім'я
регістра є іменем сигналу JTAG. Наряд від цього став **167 тверджень від
12 джерел** замість 169 від 13.

`ZAVDANNYA-M2.md` оновлено: пункт викреслено з таблиці порядку, а замість
нього лишилася перевірка на дві хвилини — звірити ті самі рядки в
datasheet, коли він і так буде відкритий. Два незалежні джерела на той
самий факт того варті.

Якщо ви вже почали з нього — перепрошую за витрачений час. Висновок для
нас обох записаний там же: «недосяжне джерело» і «я не знайшов» — різні
речі, і перше треба доводити.
