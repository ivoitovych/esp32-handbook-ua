# Реєстр питань М2

Тіла питань — у датованих файлах `m2-<UTC>-pytannya.md`. Цей файл
лишається покажчиком: із `ZAVDANNYA-M2.md` посилання ведуть сюди.

Питання сюди потрапляє тоді, коли воно **блокує** роботу або коли
рішення не очевидне з завдання. Дрібне, що не блокує, краще зробити й
описати у звіті: паралельна робота втрачає сенс, якщо кожен крок чекає
на підтвердження.

Правило «знахідка без реакції — незавершена робота» діє й тут. У цьому
реєстрі воно вперше **перевірюване**: питання без відповіді видно як
рядок, а не як абзац, що загубився серед інших.
