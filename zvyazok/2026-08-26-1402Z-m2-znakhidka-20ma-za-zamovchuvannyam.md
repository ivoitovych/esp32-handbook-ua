# «За замовчуванням драйвер налаштований приблизно на 20 мА» — джерела немає

- **Де:** `manual/05-elektronika.md:54`, `manual/47-klyuchi.md:3`.

**Стан звірки.** У ESP32 Series Datasheet числа для сили драйвера **за
замовчуванням** немає взагалі: 40 мА там наведено для **максимальної**
сили. У ESP-IDF теж немає міліампер —
`components/hal/include/hal/gpio_types.h`:

```c
GPIO_DRIVE_CAP_0       = 0,    /*!< Pad drive capability: weak          */
GPIO_DRIVE_CAP_1       = 1,    /*!< Pad drive capability: stronger      */
GPIO_DRIVE_CAP_2       = 2,    /*!< Pad drive capability: medium */
GPIO_DRIVE_CAP_DEFAULT = 2,    /*!< Pad drive capability: medium */
GPIO_DRIVE_CAP_3       = 3,    /*!< Pad drive capability: strongest     */
```

**Пастка, через яку це варто перевірити двічі.** 20 мА в datasheet є —
але це IOH домену **VDD_SDIO**, зовсім інша річ із тим самим числом.
Хто шукатиме підтвердження побіжно, знайде його і помилиться; я мало не
записав це як збіг.

**Оцінка.** «20 мА» як половина від максимуму на середній силі —
правдоподібний висновок і майже напевно правильний на практиці. Але це
**висновок, а не цитата**, і класу `A` він не дістає. Це не спростування:
це твердження без джерела, яке виглядає як твердження з джерелом.

**Пропозиція:** або переписати як висновок («за замовчуванням драйвер
стоїть на середній силі — приблизно половина від максимальної»), або
лишити число з явною позначкою, що первинного джерела на нього немає.
