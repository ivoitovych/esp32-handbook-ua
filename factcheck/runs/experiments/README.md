# Витяжки дослідів: самі одиниці, бо насіння не записано

## Чого тут бракує і чому

Три досліди по сто одиниць добиралися командою

    sort -R  →  перші 100

**і насіння не записано.** Знайшов це М1 (лист 1118Z), і зауваження
слушне: це рівно те правило, яке ми обидва вимагаємо від помічників —
відсоток можна цитувати лише з витяжки, чиє насіння записане.

`sort -R` без `--random-source` бере випадковість із системи, тож
**повторити добір неможливо**. Ані мені завтра, ані будь-кому.

## Що зроблено натомість

Записано **самі витягнуті одиниці**, поіменно. Це слабше за насіння в
одному й сильніше в іншому:

- **слабше:** не можна перевірити, що добір був чесний. Хтось мусить
  вірити, що я не перекидав витяжку, доки число не сподобається;
- **сильніше:** результат відтворюється точно. Будь-хто візьме ці
  самі сто одиниць і перерахує розклад, не покладаючись на те, що
  `sort -R` поводиться однаково на іншій машині.

## Як робити правильно наступного разу

    shuf --random-source=<(yes SEED) -n 100

або, як у `tools/sample.py`, добір у Python із `random.seed(N)` і
записаним `N`. Насіння **не з годинника** — інакше воно так само не
повторюється.
