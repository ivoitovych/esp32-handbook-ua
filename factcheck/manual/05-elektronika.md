### T-05-020 · proza · рядок 46

**Книга каже, дослівно:**

> `R = (3.3 − 2) / 0.007 ≈ 185 Ом` → беремо найближчий більший, 220 Ом.

**Доказ**

- **Клас:** 🔵 D — обчислення — перевіряється арифметикою, зовнішнє джерело не потрібне
- **Джерело:** tools/arytmetyka.py
- **Розрахунок:**
  30 перевірок, усі збіглися. Найважливіші:
    (3.3 − 2) / 0.007            = 185.7 Ом      → книга: 185, беремо 220
    5 × 20 / (10 + 20)           = 3.33 В        → дільник HC-SR04
    0.2 × 40 + 2 × 150           = 308 мА·с      → 308/3600 = 0.0856 мА·год
    2000 / 0.106                 = 18 868 год    → «понад два роки»
    0x6000 / 1024                = 24 КБ         → розділ nvs
    (4×1024 − 64) / 1024         = 3.94 МБ       → «приблизно 3.9»
    115200 / 10                  = 11 520 Б/с    → «близько 11 КБ/с»
    256 / 11520                  = 22.2 мс       → «частіше ніж кожні 22»
    65536 × 1.0 / 20             = 3277          → duty серво, 16 біт
    65536 × 1.5 / 20             = 4915
    65536 × 2.0 / 20             = 6554
    3.7 / 200 000                = 18.5 мкА      → дільник вимірювання
    4700 / 3                     = 1567 Ом       → «близько 1.6 кОм»
    128 − 16                     = 112           → придатних адрес I²C
    750 / 8                      = 93.75 мс      → DS18B20 при 9 розрядах
    120 / 2                      = 60 Ом         → два термінатори
    320 × 240 × 2 / 1024         = 150 КБ        → кадровий буфер
    320 × 240 × 2 × 8 / 40e6     = 30.7 мс       → той самий кадр по SPI
    12 + 36 + 32 + 27            = 107 мА·с      → цикл логера
    899 × 0.030                  = 26.97 мА·с    → фаза сну
    96 × 107 / 3600              = 2.85 мА·год   → за добу
    1750 / 2.85                  = 614 діб

### T-05-021 · proza · рядок 48

**Книга каже, дослівно:**

> Резистор 220–330 Ом підходить майже завжди.

**Доказ**

- **Клас:** 🔵 D — обчислення — перевіряється арифметикою, зовнішнє джерело не потрібне
- **Джерело:** Закон Ома, застосований до `T-05-019` (падіння `1.9–2.3 В`, датшит Kingbright WP7113ID) і живлення `3.3 В`
- **Дослівно з джерела:**
  > R = (Vсупply - Vf) / I
  > 
  > При Vf = 2.0 В (типове з datasheet), Vсупply = 3.3 В:
  >   R = 220 Ом → I = (3.3 - 2.0) / 220 = 5.9 мА
  >   R = 330 Ом → I = (3.3 - 2.0) / 330 = 3.9 мА
- **Спосіб і дата:** обчислення, 2026-08-26
- **Нотатка:** Чесна розбіжність, а не збіг один-в-один: заявлений струм у книзі — «5–10 мА» (T-05-019), а резистори 220–330 Ом за законом Ома дають 3.9–5.9 мА — нижній край діапазону, не середину. Це не помилка: консервативніший струм означає довший ресурс LED і менший нагрів резистора, і «майже завжди підходить» лишається правдою (світить помітно на будь-якому зі значень). Але хто підставить формулу буквально під «5–10 мА», отримає інший резистор (130–260 Ом).
- **Прохід:** m2-19-elektronika-05
